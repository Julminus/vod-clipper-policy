vod-clipper privacy policy

Last updated: 16 November 2026

vod-clipper is a personal desktop application used only by its owner, on the owner's own computer, with the owner's own YouTube channel.

What Google data it uses

  • youtube.upload: to upload clips the owner has approved to the owner's channel.
  • youtube.readonly: to show which channel is connected and to confirm that uploads finished.

Where data is kept

The Google sign-in (an OAuth refresh token) and the connected channel's ID are stored only on the owner's computer, in Windows Credential Manager. Videos and clips stay on that computer until they are uploaded or deleted.

Sharing

vod-clipper does not send Google user data to any server other than Google's own APIs. It does not sell, share or transfer that data to anyone, and does not use it for advertising.

vod-clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. vod-clipper uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, or by running python -m clipper youtube-disconnect, which deletes the stored sign-in.
